# Focusly — برنامه‌ریز هوشمند

اپلیکیشن وب و PWA فارسی (RTL) برای برنامه‌ریزی روزانه، تمرکز با پومودورو و بازبرنامه‌ریزی هوشمند هفتگی.
نام و برند رسمی محصول Focusly است. تنظیمات برند در `src/config/brand.ts`، نام نصب‌شونده در `public/manifest.webmanifest` و عنوان مرورگر در `index.html` قرار دارد. پیشوند ذخیره‌سازی محلی عمداً `planner` باقی مانده تا اطلاعات کاربران فعلی حفظ شود.

## وضعیت پروژه (صادقانه)

- منطق اصلی (برنامه‌ریز هفتگی، تایمر پومودورو، فیلتر/اعتبارسنجی کارها، گزارش هفتگی، تاریخ‌ها) با ۳۷ تست خودکار پوشش داده شده و تست‌ها پاس می‌شوند.
- رابط کاربری (React)، لایه‌ی Supabase و Service Worker نوشته شده‌اند، اما **در محیطی که این کد ساخته شد اینترنت نبود**، پس `npm install`، `npm run build` و اجرای مرورگری انجام نشد. اولین اجرای شما باید این‌ها باشد (بخش «راه‌اندازی»). اگر خطای TypeScript یا Build دیدید، پیام خطا را بفرستید تا رفع شود.
- فایل APK/AAB اندروید ساخته نشده است؛ فقط ساختار پروژه برای Capacitor آماده است (بخش «اندروید»).

## راه‌اندازی (ویندوز / PowerShell)

پیش‌نیاز: Node.js نسخه‌ی ۲۰ یا بالاتر برای اجرا و Build. اجرای `npm test` به Node.js نسخه‌ی ۲۲.۶ یا بالاتر نیاز دارد (چون TypeScript را مستقیم با `--experimental-strip-types` اجرا می‌کند).

```powershell
npm install
npm test          # تست‌های منطق
npm run dev       # اجرای توسعه، آدرس: http://localhost:5173
```

بدون هیچ تنظیمی برنامه در **حالت دمو** کار می‌کند (داده‌ها فقط در IndexedDB همین مرورگر).

## اتصال به Supabase

این نسخه از قبل به پروژه‌ی Supabase `student-planner` متصل شده است.
تنظیمات عمومی اتصال در `.env.local` قرار دارد. برای مراحل تأیید ایمیل، URLهای مجاز و تست ورود، فایل `SUPABASE_SETUP.md` را ببینید.

**هرگز کلید `service_role` یا Secret API Key را در فرانت‌اند قرار ندهید.**

## همگام‌سازی و آفلاین

- همه‌ی تغییرات اول در IndexedDB ذخیره می‌شوند و برنامه آفلاین هم کار می‌کند.
- پس از ورود و هر تغییر (و با برگشت اینترنت) همگام‌سازی انجام می‌شود. شناسه‌ها UUID سمت کلاینت‌اند و با `upsert` ارسال می‌شوند؛ پس رکورد تکراری ساخته نمی‌شود.
- اگر نسخه‌ی سرور از ویرایش محلی جدیدتر باشد، نسخه‌ی سرور حفظ می‌شود (بازنویسی بی‌صدا نداریم) و تعداد تعارض‌ها نمایش داده می‌شود.
- حذف کارها «حذف نرم» است (`deleted_at`) تا حذف هم همگام شود.
- داده‌های حالت دمو به حساب کاربری منتقل نمی‌شوند.

## برنامه‌ریز هوشمند هفتگی

کارهای ناتمامِ گذشته کاندید می‌شوند. امتیاز = اولویت×۱۰ + (روزهای تاخیر، حداکثر ۱۴)×۲ + تعداد انتقال قبلی×۵. هر کار به اولین روزی که ظرفیت کافی دارد می‌رود (ظرفیت روزانه از تنظیمات، منهای کارهای از قبل برنامه‌ریزی‌شده). کاری که جا نشود یا از یک روز کامل طولانی‌تر باشد جابه‌جا نمی‌شود و هشدار نمایش داده می‌شود. پیش‌نمایش قابل ویرایش است و فقط پس از تایید صریح اعمال می‌شود. `originalDate` ثابت می‌ماند و `carryOverCount` یک واحد زیاد می‌شود.

## پومودورو

وضعیت تایمر با برچسب زمانی در `localStorage` ذخیره می‌شود (نه رمز یا داده‌ی حساس)، پس رفرش صفحه یا بستن تب آن را خراب نمی‌کند. فقط جلسه‌ی تمرکزِ کامل ثبت می‌شود؛ بازنشانی جلسه را شمرده نمی‌کند. بعد از چهار تمرکز، استراحت بلند.

## یادآوری‌ها

یادآوری‌ها درون‌برنامه‌ای‌اند و فقط وقتی برنامه باز است کار می‌کنند. مجوز اعلان مرورگر فقط با کلیک کاربر در تنظیمات درخواست می‌شود. اعلان پس‌زمینه (Push) پیاده‌سازی نشده است.

## استقرار روی Netlify

1. مخزن را به Netlify وصل کنید (فایل `netlify.toml` تنظیمات build و بازنویسی مسیرهای SPA را دارد).
2. در Site settings → Environment variables مقادیر `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را اضافه کنید.
3. Deploy کنید. برای نصب PWA روی موبایل سایت باید با HTTPS باز شود (Netlify این را فراهم می‌کند).

## بسته‌بندی اندروید با Capacitor (بعداً)

نیازمند Android Studio است.

```powershell
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli
npx cap init "Focusly" app.example.focusly --web-dir=dist
npm run build
npx cap add android
npx cap sync
npx cap open android
```

نکته‌ها: `appId` را در `capacitor.config.ts` به شناسه‌ی نهایی خود تغییر دهید؛ بعد از نصب Capacitor می‌توانید فایل کانفیگ را با `import type { CapacitorConfig } from '@capacitor/cli'` تایپ کنید؛ آدرس Supabase باید در Redirect URLs مجاز باشد؛ برای انتشار در گوگل‌پلی آیکون، امضا و سیاست حریم خصوصی لازم است. اعلان پس‌زمینه نیاز به پیاده‌سازی جداگانه (مثلاً `@capacitor/local-notifications`) دارد.

## ساختار

```
src/
  components/   اجزای مشترک رابط (Layout, Modal, Toast, ...)
  pages/        صفحه‌ها
  features/     tasks, planner, pomodoro, analytics, auth, reminders
  services/     repository (IndexedDB) و sync (Supabase)
  lib/          idb, supabase, notify, id
  utils/        تاریخ و قالب‌بندی فارسی
  config/       brand.ts
supabase/migrations/0001_init.sql, 0002_accent.sql
tests/          تست‌های منطق (node:test)
```

## امکانات تکمیلی

- کارها دارای درس و نشانگر امتحان هستند؛ برنامه‌ریز برای امتحان‌های نزدیک وزن فوریت بیشتری در اولویت‌بندی اعمال می‌کند.
- صدای پایان پومودورو، لرزش و شروع خودکار مرحله‌ی بعد از تنظیمات قابل کنترل‌اند.
- خروجی JSON از داده‌ها در تنظیمات فراهم است. ورود فایل فعلاً فقط اعتبارسنجی و نگه‌داری موقت انجام می‌دهد و باید قبل از استفاده‌ی عملی، مسیر بازیابی امن تکمیل شود.
- توابع نقشه‌ی حرارتی ۹۱ روز اخیر و زمان تمرکز به تفکیک درس به آمار اضافه شده‌اند.

## محدودیت‌های شناخته‌شده (MVP)

- برای فعال‌شدن درس/امتحان و حذف حساب، migration شماره‌ی `0003_student_features.sql` را در Supabase SQL Editor اجرا کنید. حذف حساب با تابع امن سمت سرور انجام می‌شود.
- تعارض‌ها بر اساس `updated_at` حل می‌شوند و اختلاف ساعت دستگاه می‌تواند اثر بگذارد.
- اشتراک Pro فقط یک جایگزین «به‌زودی» است.
